utils
=========

dotfiles, fonts, configs, colorschemes, etc


## Manifest

Default locations for tool configs. 

- ghostty: `tool_configs/ghostty/config` → ~/.config/ghostty/config
- vim: `tool_configs/vim/vimrc` → ~/.vimrc, `tool_configs/vim/colors` → ~/.vim/colors, `tool_configs/vim/pack` → ~/.vim/pack
- zsh: `tool_configs/zsh/zshrc` → ~/.zshrc, `tool_configs/zsh/p10k.zsh` → ~/.p10k.zsh (see [docs/zsh_installation.md](docs/zsh_installation.md))
- fonts: `fonts/AnonymousPro`, `fonts/Terminus` → OS font directory
- Claude Code global config: `agents/AGENTS.md` → ~/.claude/CLAUDE.md

See [docs/new_machine_setup.md](docs/new_machine_setup.md) for the full new-machine checklist.
